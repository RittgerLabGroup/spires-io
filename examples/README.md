# Operational JSON examples

The maintained examples live in
[RittgerLabGroup/spires-batch](https://github.com/RittgerLabGroup/spires-batch/tree/main/examples).
Use `historical.json` and its `historical.md` walkthrough for matched VIIRS
preparation, clouds, retrieval, canopy adjustment and daily albedo. For the
complete five-tile historical-to-NRT sequence, use `workflow.json` and `workflow.md`.

This package supplies I/O APIs; the configurations are consumed by spires-batch,
not directly by spires-io. The former Sentinel-2 region/pansharpening notebooks
are no longer operations examples and remain available in Git history.
